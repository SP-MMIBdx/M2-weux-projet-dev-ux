# Binô — Consignes pour les agents

- Lire le [plan de développement](docs/plan_dev.md) avant de proposer des modifications, en particulier la méthode de travail accompagné et les conventions du cours. Consulter les dernières entrées du [journal de développement](docs/dev_log.md) pour connaître les décisions et l’état du projet.
- Pour une modification importante, expliquer le code existant et présenter un plan entre `<plan>` et `</plan>` avant de proposer du code. Steve saisit et teste les premiers changements par petits blocs expliqués. Il garde la main sur le staging et les commits.
- Utiliser `main` pour la version PHP. `dev` conserve le jalon HTML. Les commandes de lancement sont dans le [README](README.md).
- Pour une tâche qui touche au périmètre fonctionnel, consulter la [documentation technique](docs/documentation_technique.md). Pour les traitements serveur, les accès ou les données, appliquer les points pertinents de la [checklist de sécurité et de confidentialité](docs/security_privacy.md).
